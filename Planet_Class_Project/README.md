# Planet Class Project

## 📌 Project Overview

This project demonstrates **Object-Oriented Programming (OOP)** in Python by modeling planets as objects.

The `Planet` class represents a planet using its name, planetary type, and the star it orbits. It also includes input validation, an orbit description method, and a custom string representation for displaying planet information.

## ✨ Features

- **Planet Class:** Represents planets using a reusable Python class.
- **Attribute Initialization:** Stores each planet's name, type, and host star.
- **Type Validation:** Raises a `TypeError` if the provided attributes are not strings.
- **Value Validation:** Raises a `ValueError` if any required attribute is empty.
- **Orbit Method:** Returns a description of the planet orbiting its star.
- **Custom String Representation:** Displays planet information in a readable format.
- **Multiple Objects:** Demonstrates the class using Earth, Jupiter, and Neptune.

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project directory.
3. Run the Python file:

   ```bash
   python planet.py
   ```

   Replace `planet.py` with the actual name of your Python file if it differs.

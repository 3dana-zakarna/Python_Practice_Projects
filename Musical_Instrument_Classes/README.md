# Musical Instrument Classes

## 📌 Project Overview

This project demonstrates the fundamentals of **Object-Oriented Programming (OOP)** in Python by creating a class that represents musical instruments.

Each instrument has a name and an instrument type. The class provides methods to display a message about playing the instrument and retrieve information about its instrument family.

## ✨ Features

- **MusicalInstrument Class:** Represents a musical instrument using a reusable class.
- **Object Initialization:** Stores the instrument's name and type.
- **Play Method:** Prints a friendly message about playing the instrument.
- **Get Fact Method:** Returns a description of the instrument's family.
- **Multiple Objects:** Creates and demonstrates different instruments, including an oboe and a trumpet.

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Open a terminal in the project directory.
3. Run the Python file:

   ```bash
   python musical_instrument.py
   ```

   Replace `musical_instrument.py` with the actual name of your Python file if it differs.

# Linked List Implementation

## 📌 Project Overview

This project implements a **Singly Linked List** in Python using Object-Oriented Programming (OOP).

A linked list is a linear data structure consisting of nodes. Each node stores an element and a reference to the next node in the sequence.

The implementation supports adding elements, removing elements, checking whether the list is empty, and tracking the number of elements.

## ✨ Features

- **Node Creation:** Each node stores an element and a reference to the next node.
- **Initialize an Empty List:** Creates a linked list with no elements.
- **Check if Empty:** Determines whether the linked list contains any elements.
- **Add Elements:** Adds new elements to the end of the list.
- **Remove Elements:** Removes the first occurrence of a specified element.
- **Track Length:** Maintains the number of elements in the list.
- **Update Head Reference:** Handles removal of the first node correctly.
